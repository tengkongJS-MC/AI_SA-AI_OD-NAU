### 2.2 "爆款 / 高频 / 系列化"的选题规律
1. **最常被反复追更的是"成系列、成 IP"的栏目**（这是本号最明显的规律，也是选题的第一抓手）：
   - 社会实践两大王牌系列：**"青春实践行"**（30+ 篇）与 **"AI青春行"**（30+ 篇），且同一实践团常**"分站/过程稿 + 总纪实稿"成对连发**、同一团队多天连更（如智慧/慧X/智X四字团队雅号体系）。
   - 假期陪伴系列 **"小AI陪你过寒假/暑假"**（10+ 篇），把"线下活动 + 线上打卡 + 主题征集"做成固定栏目。
   - 人物IP **"AI菁英"**、赛事预告/回顾 **"AI尚竞赛"**、科普 **"AI尚科普"**、**"青年大学习"** 每周转；品牌前缀稳定，读者有预期。
2. **"预热—收官"成对推送是刚需节奏**：同一活动几乎必有两稿——报名/预告稿（"…开始报名啦/火热来袭/等你来"）与总结/成果稿（"…圆满落幕/收官/结束"）。写稿时要意识到：多数推送不是孤篇，而是**系列中的一环**。
3. **"榜样式人物 + 逆袭/坚持叙事"自带传播力**：获奖、就业深造先锋、国奖得主、保研上岸是固定流量点，多配"金句 + 战绩 + 成长故事 + 感言/寄语"。
4. **政策/党建主题能"借势造节"**：两会、五四、七一、国庆、抗战纪念、节气民俗、教师节、母亲节等都能做成应景推文（尤以节气为最稳定的小流量，多为纯海报）。

### 2.3 选题建议（给策划的快速筛选器）
选一个题，至少命中下面一条才立项：
- **有没有"可展示的成果或成绩"？**（名次/奖牌/突破/数据/名单/作品）
- **有没有"人物故事或真实引语"？**（师生的付出、感言、领导者寄语）
- **有没有"节点/时令/热点"可借？**（开学毕业、竞赛季、实践季、节庆、政策时点）
- **是不是"必做的规定动作"？**（党团教育、公示、须知、招生迎新）
避免：只有口号、没有事实/画面/人物/数据的"空转推文"（语料中这正是被标记为低质量的一类）。

## 第 3 章　标准文章结构模板（附实例）

语料里正文高度模板化。**好消息是模板拿来即用、效率极高；坏消息是模板用得太多会"千文一面"。**本技能给你"标配模板 + 防呆变体"，两者都教。

### 3.0 通用"四段式母版"（几乎所有长文都能套）
```
① 开头（1 段）：起笔定调
② 总起/导语（1 段）：时间地点主体事件，或一句总论点
③ 正文（多段，用加粗小标题分层）：并列展开 / 时间线 / 分站分人物
④ 结尾（1 段）：意义升华 +（祝福/号召/展望/报名引导/鸣谢）之一
⑤ 页脚：固定署名信息栏（见 5.4）
```

### 3.1 按文章类型的推荐骨架（含该文种必备要素与字数参考）

#### A. 捷报/获奖/科研突破稿
- **骨架**：亮眼标题（数据或破纪录点题）→ 总起（时间+赛事+结果，"近日/月日，…斩获…"）→ 分站/分项成绩（按时间或站次逐条，含队名/人名/数字）→ 赛事背景科普（"据悉，…被誉为…"）→ 意义+幕后（教师指导、以赛促学理念）→ 未来展望。
- **范文句（原文）**：`值得注意，在大赛武汉站中斩获的银牌，实现了我校在该赛事区域赛级别银牌"零的突破"，刷新了历史最好成绩。`（#0）
- 字数参考：400—700 字（多用于图文短稿）。

#### B. 榜样人物 / 经验分享稿
- **骨架**：抒情或金句开场 → 人物卡片（班级+关键荣誉"硬核战绩"）→ 追逐之路（按"起步→瓶颈→破局→结果"讲故事）→ 人物原声感言（"攀登者说"）→ 意义金句收束 →（连载则加"下期预告"钩子）。
- 高频子栏目名（可直接沿用）：**人物卡片 / 硬核战绩 / 追逐之路 / 攀登者说 / 我的tag / 下期预告**（#25）。
- **原声引语最增信**，例：#280 `'智慧农业是交叉学科的前沿阵地，需要既懂农学又懂人工智能。'张如昕说…`。
- 字数参考：700—1100 字。

#### C. 会议/要闻/换届/研代会稿（庄重公文腔）
- **骨架**：时间地点主体句起 → 依议程推进（国歌启幕→工作汇报→候选人竞职演说/答辩→投票→领导讲话"三点期望"→校歌/闭幕）→ 意义总结 + 未来展望段。领导期望喜欢用"一/二/三"动宾四字格排比（见第 4 章）。
- 字数参考：500—800 字；此类最容易雷同，务必换活动名称、换具体人名事迹，忌整段照抄往期（语料 #146-148 三篇调研稿已因几乎逐字雷同被标记为反面案例）。

#### D. 活动预告/报名稿（带 CTA）
- **骨架**：吸睛引子（先抛价值或悬念）→ 活动是什么（背景意义）→ 信息清单（时间/地点/对象/报名方式/截止）→ 奖项或激励 → 二维码/群号 → 号召语。
- 必备要素（漏了就废）：**时间、地点、对象、报名渠道（二维码/链接/QQ群/报名表）、截止时间、激励/奖励**。
- 结尾号召例：#29 `冬天的冷，挡不住奔跑的热！`；#427 全篇游戏化招新文案可作范本。

#### E. 活动总结/收官稿
- **骨架**：总括（时间+活动+规模/数据句）→ 分环节过程（作品/选手/现场，含名单）→ 作品或风采展示 → 意义升华（"不仅…更…"）→ 鸣谢/展望。
- 常与预告稿成对发布、标题互为镜像（#223 结营 ↔ #224 开营）。
- 字数参考：600—1100 字。

#### F. 社会实践/三下乡纪实稿
- **骨架**：总起（时间+队伍名+带队老师+主题/目标）→ 加粗小标题分站/分天展开（每站"到了哪+做了什么+意义句"）→ 人物/现场细节 → 总收（"本次…后续将…"+ 口号/展望）。
- 固定栏目前缀：**"青春实践行 |"**、**"AI青春行 |"**；团队名爱用四字雅号并加引号（如"'农'墨重彩，'智'绘乡村""智传薪火""慧X"）。
- 字数参考：400—800 字/篇（分站稿可更短）；忌"过程稿"与"总纪实稿"整段重复（语料反面案例）。

#### G. 党建思政/红色教育稿
- **骨架**：金句/诗句起笔 → "为…目的句"铺陈 → 活动环节分述（观展/宣讲/实践/观影…）+人物话语 → 意义升华（把"红色基因/初心使命/时代新人"落到具体点上）。
- 用词尺度：庄重但**要有事实、环节细节、人物引语、数据**，避免口号堆砌；同一升华句式勿在相邻推送重复（语料 #87=#92 已踩雷）。
- 字数参考：500—900 字。

#### H. 通知公告/须知/倡议（事务体）
- **骨架**：称呼/直接入题 → 分条列项（一、二、三…或 01/02/03）→ 每一条"事项+说明"（格式/时间/材料/联系方式）→ 附件/联系方式 → /END/ 收尾。
- 例：#116 书评大赛通知（"各班级：…现将有关事项通知如下"，一～七逐条），#129 夏令营开营通知（课程安排/班型/地点/报名时间与方式/温馨提示）。
- 语言：平实严谨，不堆抒情，标题即"关于…的通知"或带口号前缀。

#### I. 节气/节日纯图文（极短）
- 语料中大量节气文只有一句古诗/对仗题（如 #63"一叶知秋至，万物悦丰收"），正文为零、全靠配图海报。**规律：标题就是全篇**。要写得雅、对仗、贴时令；正文可用一句祝福收束。

### 3.2 开头模式库（六式，附原文，写作时挑一用）
1. **新闻导语式（最常用、最稳）**：`3月11日下午，人工智能学院在滨江校区召开新学期工作会议。`（#125）
2. **目的状语长句 + 时间地点事件（政务通告式）**：`为进一步加强我院与…的联系，3月17日-18日，…赴苏州开展招生宣传系列活动。`（#74）；会议/活动文大量使用（#130/131/141/146…）。
3. **抒情排比/时节引子（预热、文艺类）**：`春华秋实结硕果，先锋领航正当时。`（#127）；`金秋九月，稻谷飘香…`（#21）。
4. **先抛结果/成绩（回顾类）**：`在刚刚落幕的…排球赛中，我院男排实现历史性突破：摘得季军奖杯。`（#102）
5. **设问互动/人称唤回（栏目、招新、生活类）**：`春天到了…镜子里的自己突然"膨胀"成plus版？别慌！小AI秘制《…指南》新鲜出炉`（#99）。
6. **对象称呼式（函件体，面向外部）**：`尊敬的用人单位：感谢…`（#137）。
> 规则：**别篇篇用同一种开头**；可把"导语式"留作会务/党建默认，预热/人物/栏目类多试试 3/5 式增加新鲜感。

### 3.3 结尾模式库（六式）
1. **意义升华 + 未来展望（万能收尾，最常用但最腻）**：`…学院将持续…为…注入…动能。`——请谨慎使用，太多则无感。
2. **祝福 / 号召读者（拉近距离）**：`祝愿所有考研学子在复试中自信发挥，圆梦理想院校！`（#133）
3. **报名/关注引导（CTA，预告稿用）**：`感兴趣的同学请扫描下方二维码…`；`让我们相约5月7日…`
4. **致谢鸣谢（感谢评委/工作人员/赞助/到场）**：#168 末尾连谢评委、赞助方安踏、台前幕后、每一位现场的你。
5. **名单 / 合影 / 展示收尾（回顾稿）**：`…评委嘉宾、参赛选手及工作人员上台合影留念。`
6. **以 END 标记收正文**，再跟页脚（END 写法全号极不统一，建议本单位统一为 `END`，见 5.5）。
> 收尾搭配建议：**会议/党建=升华式；活动预告=CTA式；活动总结=鸣谢或名单式；人物稿=金句+连载钩子；情感/节日=祝福式**。

## 第 4 章　语言风格指南（词汇 / 句式 / 修辞）

### 4.1 语气基调
- **主基调**：四字成语+对仗+排比偏多的"宣传笔"，情绪积极、充满干劲（青春、奋斗、突破、希望）。
- **两套语体按文种切换，不得串味**：
  - 政务/党建/要闻：正式、庄重，多用"纵深推进、严格落实、立德树人、凝心聚力、新质生产力、使命担当"；
  - 活动/人物/栏目/招新：亲切、活泼、带梗、可设问，多用"解锁、get、火热、重磅、小AI"。
- **该号的"语言人格"**：爱把硬事说软（用比喻/意象/诗意），爱把小事升华到意义（"不仅…更是…"），爱造四字/对仗金句当标题与小节题。

### 4.2 高频词库（写作时优先取用，保证"像这个号写的"）
- **结果动词**：斩获、荣获、勇夺、夺得、实现、刷新、打破、摘得、晋级、收官、落幕、圆满、告捷、开门红。
- **过程动词**：举办、承办、开展、举办、举行、亮相、亮相、集结、出发、奔赴、深耕、逐梦、启航、扬帆、护航、赋能、助力、点亮。
- **评价语**：扎实的、过硬的、出色的、显著的、深入、热烈、圆满、硬核、高燃、有温度/有深度/有态度。
- **四字熟语/口号高频**：凝心聚力、踔厉奋发、砥砺前行、奋楫笃行、乘风破浪、劈波斩浪、以赛促学、以赛促教/研/创、强农兴农、科技兴农、筑梦/逐梦、新篇章/新征程/新图景/新答卷、赓续…薪火、让…落地生根。
- **必背"破纪录/首创"句式**：`…实现…"零的突破"，刷新了历史最好成绩。`（#0 原文，反复出现，最该学也最不该乱用——只能用于真实首创）。

### 4.3 句式与修辞模板（附原文范例）
1. **排比三连**（最常用，用于意义段/寄语）：
   - #126 `搭建青年成长"加油站"、思想碰撞"议事厅"、实践创新"孵化器"`；
   - #139 拆字寄语：`"'人'是立身之本…'工'是立业之基…'智'是发展之源…'能'是担当之责…以'人工智能'四字为铭"`
   - #141 `一、立身为旗，做知行合一的引领者；二、谋局善治…；三、凝心聚力…`
2. **对仗/四字金句当标题与小节题**：#127`春华秋实结硕果，先锋领航正当时`；#176`烟火藏诗意，家味暖同窗`。
3. **比喻 + 意象收束**：#3`当代码在童真的指尖流淌，创新的种子已悄然萌发…`；#49`让桥梁不仅是连接两岸的建筑，更是传承与发展的坚固纽带`。
4. **设问互动**（栏目/生活稿）：#191`《答案之书》最好的答案，藏在"加入我们"之后。`
5. **"把…写在…"式宏大落地**（学院灵魂句式）：`把论文写在祖国大地上`、`让代码与灵感在田间地头碰撞`。
6. **口语化三连（去八股）**：#145`打造同学们"信得过、靠得住、用得上"的优秀组织`。
7. **人物原声直引**（增信利器，实践/榜样稿多用），加引号 + "某某说"。

### 4.4 标题命名规范（含语料统计依据）
语料统计：500 篇标题平均约 32 字；**约一半（约 247 篇）用 `｜ / | / 丨` 作主分隔符**；约 **200+ 篇含引号**（引号包团队名/主题口号）、约 **110 篇含感叹号**。综合出下列命名法：

1. **品牌栏目 + 竖线 + 副题（最典型，优先用）**：`AI青春行 | "…实践团…"`；`AI菁英 | 张思源：知不足而奋进…`；`工坊π力 | 第二届电子联盟…火热报名中`。前段=识别品牌，后段=具体事件，积累栏目资产。
2. **对仗口号/主题句 + 破折号 + 事件**：`凝心聚力启新程 砥砺奋进谱新篇——…召开新学期工作会议`。
3. **引号"活动主题" + 完整句**：`"AI深耕，青春稼穑"——2025级新生启航行动`。
4. **数据/悬念/感叹前置**：`1银4铜｜我院…斩获佳绩`（数据型）；`你准备好让世界失重了吗？`（悬念型）；`重磅！/火热来袭！`（感叹型）。
5. **机构全称 + 活动 + 结果动词**（庄重，用于会议/党团，会偏长、可读性差，慎用长串）：`智慧农业学院（人工智能学院）召开2025级新生班主任会…`。
6. **谐音/专业梗（加分创意）**：`"Hello World，码上开打"篮球赛`（#144）、`创意有"坊"！`（#130）。

**标题自查三问**：① 有没有关键词让读者一秒知道"这是啥活动/谁得了啥"；② 分隔符/引号是否规范统一；③ 会不会超过一屏、微信列表被截断（语料中 ≥28 字超长标题会截断，作负面提醒）。

## 第 5 章　排版格式规范

### 5.1 文字排版习惯
- **短段短句优先**：几乎一句一段、长短句交错；多行一句的排比诗化排版（#127/#149）非常普遍，适配手机阅读。
- **小标题体系**（全号最主流的三种，任选一种并在一篇内保持一致）：
  - `**一、…** / **二、…**`（政务、党团多用，"（一）（二）"再分层）；
  - `**01 / 02 / 03…**`（预告、颁奖、攻略多用）；
  - `**加粗关键词短语**`（如 `**活动亮点抢先看**`、`**关于我们**`、`**人物卡片**`）。
- **关键信息加粗**：时间、地点、报名方式、截止、特别提醒等一律加粗，便于扫读。
- **文内分隔**：人物/并列项之间常用 `✦`、`•`、`★`、emoji 或空行做视觉分隔（#2 人物展用 ✦/• 分割多位人物）。
- **emoji**：语料文本中 emoji 极少（文本导出会丢失），但实际排版会在情绪点少量点缀（如 ♡、🔥、🏀、✨、♥ 出现在毕业/歌会/情感稿）。原则：**正式/党团稿不用或极少用；青春/节日/栏目稿可点缀，不泛滥**。
- **视觉图配说明**：重要配图下常有一行说明（如"院系杯颁奖合照""队员相互加油"），起注释/过渡作用；封面与活动图由 `push_pic_skill` 另行产出。

### 5.2 二维码 / 报名 / 附件处理
- 报名多附 **"**长按识别二维码**/ 扫码进群 / 扫描下方二维码"** 提示，并给 QQ 群号/邮箱/报名表附件（.docx）。
- 涉及文档附 `附件X：…` 超链；涉及外链写"请点击文末【阅读原文】查看"。
- 温馨提示类（如名额有限）常用短句分条或加粗提示。

### 5.3 正文结束标记
正文与页脚之间常加结束符（如 `END`、`-END-`、`— END —`、`= END =`、`/END/`、`·END·` 等）。**语料显示该号至少有 7 种 END 写法并存**——写作时请本单位统一为简单的一种（建议 `**END**`），并在质检单里核对。

## 第 7 章　策划案写作工作流（核心：交互式问答引导）

本章把"从接到任务 → 产出推送"做成**一段可交互的问答流程**。它既是给作者的"接单 SOP"，也是让 AI 当"写作搭档"时的**主动追问脚本**。**不要一上来就闷头写**，先逐阶段把下面问题过一遍；AI 扮演助手时按阶段逐条提问，一次 2—4 问，别把问题一股脑倒给用户。

### 阶段 0　接单与信息补全（"缺什么问什么"）
先自问并（必要时）向用户确认：
- **为什么要发？**（宣传成绩/树立榜样/通知活动/思想教育/招生招新/记录过程/应景造节）
- **给谁看？**（在校生/家长考生/校友/用人单位/内部师生）
- **已有素材够不够**：活动/获奖的全名、具体时间地点、数据与名单、现场照片、人物原声/感言、指导老师寄语、主办承办单位、二维码/群号/报名渠道、配图情况。
- 若用户只给一句"写篇××的推送"且信息不足，AI 应**按上面清单追问最关键的 2—4 项**，而不是凭空编造；其余用"合理默认值 + 交付时标注"处理。

### 阶段 1　定类型（决定重心与骨架）
按第 2、3 章把任务归入某几类主文种，并确定"内容重心"：
- 捷报/突破 → 重心：成绩+破纪录+意义；骨架见 3.1A。
- 榜样人物 → 重心：人物故事+原声+可借鉴点；骨架 3.1B。
- 会议/党团/要闻 → 重心：议程与精神传达；骨架 3.1C/G。
- 活动预告/报名 → 重心：价值点+安排+报名；骨架 3.1D。
- 活动回顾/收官 → 重心：过程+成果+名单+鸣谢；骨架 3.1E。
- 社会实践纪实 → 重心：站点+人物+意义；骨架 3.1F。
- 通知/须知/公示 → 重心：要素齐全；骨架 3.1H。
- 节气/节日图文 → 重心：标题诗意+配图；骨架 3.1I。

### 阶段 2　找参考（匹配历史最相似案例）
关键词（如"竞赛获奖""保研分享""三下乡""党建活动"）→ 到 `data/extracted_texts.json` / 本文件章节中**检索最像的 2—3 篇**作为结构、措辞、口吻的镜像参考（语料本身即是最好的"风格例句库"）。把"别人同类文怎么开头、怎么收尾、页码格式"抄一遍骨架，再换成本次内容。

### 阶段 3　列素材清单（"按清单填空"）
按所选文种列必填/加分素材，逐项打勾，缺的催用户补：
- **捷报类**：赛事全名、级别/届次、具体成绩与名次、获奖团队/个人、是否为"首次/零的突破"、指导教师、现场照。
- **人物类**：人物班级与关键经历、战绩与荣誉、成长故事线（起点→转折→结果）、原声感言、指导老师/同学评价、一张好照片。
- **活动类**：活动全名与主题、时间地点对象、主办承办/赞助、流程与亮点、报名方式与截止、奖励/学时、现场照片、负责人/鸣谢名单。
- **党建/思政**：主题与背景政策、环节安排、到场领导/讲话要点、参与人数数据、红色知识点、现场图。
- **预告稿**另要：预告时间节点（"决赛倒计时""报名截止 X 日"）。
> 拿不到的照片/数据不要硬写细节，宁可写"详见现场图文"也别编造。

### 阶段 4　搭结构（选模板 + 定字数）
按类型选第 3 章对应骨架；按篇幅预设比例（以 600—1000 字长稿为例）：
- 开头+总起 10—15%；正文（分站/分人/分项）60—70%；结尾升华+CTA 15—20%；页脚固定。
给用户一句话确认："这篇按【活动回顾】写，骨架=总括→分环节→名单→升华鸣谢，约800字，行吗？"

### 阶段 5　写初稿（调用风格规则扩写）
用第 4 章语言库"扩写要点"，把用户的"草稿要点/素材"还原成完整段落：
- 加 4.2 词库动词、4.3 修辞；把单个数据写成"数据+意义句"；把名单人物各给一句"做了什么"。
- 用 4.4 起一个抓眼又规范标题；首段用 3.2 开头式起笔；末段按 3.3 收尾 + 5.4 页脚。
- 语言人格切换：庄重文种收着写、避免堆砌；活泼文种放开写但**别把"红色公文腔"和"网感梗"写进同一篇**。

### 阶段 6　自查校对（清单式质检）
成稿后逐项打勾，不合格就改：
- [ ] 标题是否符合命名规范、有无关键词、会不会被列表截断
- [ ] 全称是否用对："南京农业大学智慧农业学院（人工智能学院）"
- [ ] 时间/地点/对象/报名/截止等关键信息是否齐全、加粗、无缺字错字（如"第３期/７月４日"全半角是否统一）
- [ ] 数字与单位：比分、人数、名次、届次是否准确，是否有"李克强/李强"这类事实差错
- [ ] 人名、职务、机构名是否写对（防"田院长/孙建"式缺名或前后不一致）
- [ ] 是否引用真实原声/语录；引文是否有出处
- [ ] 有无过度承诺/绝对化（"不二之选""史上最强""国家级首创"须慎用）；政策表述是否稳妥有依据
- [ ] 是否有敏感表述或把部门工作拔高
- [ ] 是否包含 5.4 信息栏（图文来源/编辑/一审一校…），且 END/页脚格式统一
- [ ] 是否"图文并茂"可落地（需补图处标注 [配图]）
- [ ] 段落是否偏长；emoj占位与活泼度是否符合本篇文种
- [ ] 是否有 AI 感废话/同义堆砌/跨篇整段复用（防 #87=#92 式事故）

### 阶段 7　交付（按渠道 / 用户选择输出）
- 输出完整可粘贴的推文正文（含标题、小标题、正文、页脚信息栏、需配图占位）。
- 若用户只要策划案：输出一份"选题定位 + 结构提纲 + 素材清单 + 分工分工建议"的策划稿。
- 若本次有"AI 默认补全"的信息（如替用户补的时间/对象/数字占位符），文末单列一行提醒替换。

## 第 8 章　写作流程建议（从选题到成稿）

1. **选题立项**（用 2.3 筛选器）→ 2. **约稿/占位**：定类型与重心、排期（看 3—7 月/毕业开学季的日历档）→ 3. **素材采集**（阶段 3 清单）：照片、数据、名单、原声、寄语，最好"边办活动边收"，别等活动结束才补 → 4. **起草**：先用第 3 章骨架搭框、填事实，再润辞 → 5. **配图排版**（封面/头图/正文图 + 图说，可由 `push_pic_skill` 协助）→ 6. **三审三校**：编辑自校 → 一审（全媒体学生）→ 二审（辅导员/系口）→ 三审（学院负责人），**页脚落款与审校一一对应** → 7. **定稿发布**（晚间最佳）→ 8. **留存归档**（系列推文编号管理，避免"AI校园说①"重复、栏目期数跳号）。
- 系列化建议：**给长期栏目建编号与文案模板**（如"青春实践行/工坊π力/AI菁英"统一前缀），既能沉淀品牌，也能在排版/校对时一键防呆。
- 防同质化建议：同一活动不同场次、或"预热/收官"对稿之间，**换开头式、换结尾动作、换具体细节句**，防止 #146—148 那种"换名字发稿"的既视感。

## 第 9 章　常见问题与注意事项（写作禁忌）

### 9.1 该号高频"踩雷点"（语料实证，务必规避）
1. **模板化 / 同义堆砌 / 跨稿整句复用**：同一升华句在相邻推送原样重复（如 #87=#92），多篇会议/实践稿骨架逐字雷同。对策：每稿都换具体事实与句式。
2. **标题与正文不符**：标题承诺"月度行动指南/计划"，正文却是纯抒情无实质（#6 被点名）；或标题超长被列表截断。
3. **语言人格错乱 / 腔调混搭**：一篇里又红又专、又突然满屏网络梗；或预告稿口号过剩、干货不足（#108）。思政组织若想"去严肃化"，参考 #429"红专但有趣"人设，但要注意场合与合规。
4. **事实与文字硬伤**：
   - 错别字/杂字/缺字：如"网路(络)"（#97）、"安全反炸(诈)"、"白日化"、"实验室实验室"、"探寻解"、`**`/`&` 残留、全半角数字混用（"第３期""７月４日"）。
   - 人名/职务前后不一致（如贾惠美/贾慧美、孙建头衔、缺全名的"田院长/孙院长"）；**图片报道与地名/事项前后矛盾**。
   - 事实错误（如把"李克强总理/李强总理"写混）。
   - 引用领导人/权威论断需核对原文，不自行发挥。
5. **过度承诺 / 绝对化表达**：广告性"不二之选"、未经证实的"首创/最强"等要审；赞助商软文（简单公考、安踏、博事达、迎连帮等）若入官方号，需控篇幅、标注"特别鸣谢"、防喧宾夺主（#338 律所通稿整段照搬是反面案例）。
6. **个人信息裸露**：个人邮箱、真实姓名、证件信息、二维码未打码直接外发（如 #135 个人邮箱、学生投稿）。
7. **序号/编号不统一**：一级用"一、"，二级却用 01/A/① 混排；系列期数跳号（访谈 1→2→5→7）；两批"夏日AI校园说①…④"跨年重复。**统一编号规范并做校对**。
8. **内容合规与转载纪律**：转党建/政策/安全等用"图文来源：官方渠道"，不擅改、不"标题党"篡改；政治/政策表述"引述有出处、评价有依据"。

### 9.2 分文种"应避免"清单
- 捷报：忌把"省赛/国赛/历史首次"等帽子乱扣；忌只有奖牌没有过程与意义。
- 人物/榜样：忌写成简历流水账、无原声、无可借鉴点；忌拔高"超英"（该号自己都在倡导"反精英叙事"，如 #25"普通人也能找到自己的道路"）。
- 会议/党团：忌通篇口号无干货，忌把领导讲话机械排比到失真。
- 活动预告：忌缺时间地点对象报名截止；忌只有"重磅/燃"没有具体安排。
- 节气/节日：忌为凑节气硬写没内容的长文，纯图短帖反而得体。
- 通知/须知：忌抒情冲淡信息、忌排版错乱导致关键信息丢失。

### 9.3 常用 Q&A（防作者自己踩坑）
- **Q** 转载别人（党团视频/上级）的素材怎么写？A 加"图文来源/视频来源"，编辑栏照填本院全媒体，正文基本不动，只在首尾加本院引语与"一起来学习吧"式收束（参青年大学习系列）。
- **Q** 写了一半发现缺少数据/照片？A 用 `[配图待补]` 占位 + 提示用户补齐，别空编细节。
- **Q** 同一周发好几篇会不会太像？A 按 8 章"防同质化"换结构、换开头、换结尾动作。
- **Q** 用户给的是二手/口述材料，信息矛盾？A 优先以官方通知/原件为准，矛盾处列出来请用户拍板，不自行取舍。
