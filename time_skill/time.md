# 第二课堂学时申请与认定辅助 Skill

## 文档版本
- 版本：1.0
- 适用单位：南京农业大学智慧农业学院（人工智能学院）团委组织部
- 最后更新：2026-09-05

---

## 1. Skill 概述

本 Skill 旨在协助团委、学生会等部门高效完成第二课堂活动的 **学时申请（申请表）** 与 **学时认定（认定表）** 工作。根据是否提供活动策划书，Skill 提供两种工作模式：

- **模式一（引导模式）**：用户未上传策划书，Skill 通过分步提问，引导用户提供必要信息，自动生成符合规范的申请表和认定表。
- **模式二（解析模式）**：用户上传活动策划书（.docx/.pdf），Skill 自动提取关键信息，填充申请表和认定表，并提示需人工确认或补充的字段。

Skill 遵循学校第二课堂管理最新规定（2024年10月修订），确保活动名称、分类、学时、积分、时间节点等全部合规，并自动完成格式校验。

---

## 2. 输入与输出

### 2.1 输入
- **策划书**（可选）：活动策划文档，需包含活动背景、目的、时间、地点、对象、内容、流程等章节。
- **用户补充信息**（模式一必需）：如活动分类、参与对象、预计人数、联系人等。

### 2.2 输出
- **第二课堂活动申请表**（完整 24 项字段，符合附件1模板）
- **第二课堂活动认定表**（完整 11 项字段，符合附件2模板）
- **学时认定名单**（按附件3格式，列出参与人员学号、姓名，但本 Skill 仅生成表头及示例，需用户根据实际名单替换）
- **校验报告**：列出所有字段的合规性检查结果，标注潜在风险（如名称超字数、时间冲突、学时数量不符等）。

---

## 3. 核心规则库（必须严格遵守）

### 3.1 活动分类映射（新旧对照）
| 旧分类   | 新分类（申请时填写）                            |
| -------- | ----------------------------------------------- |
| 思想引领 | 德育实践                                        |
| 创新创业 | 智育实践                                        |
| 人文社科 | 智育实践                                        |
| 体育竞技 | 体育实践                                        |
| 公益服务 | 劳育实践（针对22级）或 公益服务（针对其他年级） |
| （新增） | 美育实践                                        |

**关键注意**：
- 劳育实践仅适用于22级同学，其他年级仍使用“公益服务”类别。
- 集赞、义卖、捐款、寄语等无实际服务时长的活动，**严禁申请公益/劳育学时**。
- 申请劳育学时，名称中人员性质统一为“志愿者”。

### 3.2 活动名称规范
- **字数**：不得超过 **16 个汉字/字符**。
- **格式**：`智农院XXX观众/选手/志愿者/……`（必须体现参与对象性质）。
- **禁止**：出现“补发”等字样。
- **示例**：`智农院年夜饭征集活动观众`（9字，合规）。

### 3.3 学时与积分数量
- 必须提前与辅导员（宋婷老师）沟通确认，方可填写。
- 一般参考：  
  - 参与类（观众/选手）通常 1~2 学时，积分 1~2。  
  - 劳育实践需在活动简介末尾注明 **单人服务时长**（2~4小时 → 0.5学时；4小时以上 → 1学时）。

### 3.4 时间节点（硬性要求）
- **申请提交**：  
  - 部门提交至监察部：报名开始时间前 **2~3 个工作日**（不含周末）。  
  - 常委上传系统：报名开始时间前 **1~2 个工作日**。
- **活动时间**：报名结束时间 **必须早于** 活动开始时间。
- **认定提交**：活动结束后 **5天内** 提交认定表及名单，**一周内** 完成系统上传。

### 3.5 其他强制性字段
- **活动地点**：如实填写（线上/具体教室）。
- **活动形式**：演出/晚会/讲座/展览/其他（若选“其他”需具体说明）。
- **参与方式**：参与人员/参赛选手/会务人员/观众。
- **活动级别**：班级/院级/校级/省级/国家级。
- **报名方式**：报名需审核 / 报名无需审核，人满即止。
- **需要签退**：是 / 否（一般为“是”）。
- **可参与学院/年级**：若不限制，则写“所有学院”“所有年级”；否则列明具体范围。
- **学时认定方式**：固定为“按名单审核认定”。
- **活动简介**：200字以内，必须出现完整活动名称，写清具体参与方式与内容，避免大段意义阐述；劳育需加单人服务时长。

## 4. Skill 工作流程

### 模式一：引导模式（无策划书）

#### Step 1：确认活动基本信息
- 提问：活动分类（从下拉选择：德育/智育/体育/劳育/美育实践）
- 提问：活动名称（提示格式、字数限制）
- 提问：活动级别（班级/院级/校级/省级/国家级）
- 提问：活动形式（演出/晚会/讲座/展览/其他，若其他需说明）
- 提问：活动地点（线上/线下具体地址）
- 提问：预计招募人数

#### Step 2：确认时间安排
- 提问：报名开始时间（精确到小时，格式 YYYY-MM-DD HH:MM）
- 提问：报名结束时间（必须早于活动开始）
- 提问：活动开始时间
- 提问：活动结束时间
- 自动校验：报名结束 < 活动开始；且当前时间距离报名开始至少2个工作日（用于申请时限）。

#### Step 3：确认参与对象
- 提问：可参与学院（若不限填“所有学院”）
- 提问：可参与年级（若不限填“所有年级”）
- 提问：参与方式（观众/选手/志愿者/会务人员等）

#### Step 4：确认负责人信息
- 提问：活动联系人（全名+学号）
- 提问：联系方式（手机号）

#### Step 5：确认学时与积分
- 提问：申请学时数量（需提示先与辅导员沟通）
- 提问：申请积分数量（同上）
- 若分类为“劳育实践”，额外提问：单人服务时长（小时），自动按规则折算学时并核对是否一致。

#### Step 6：撰写活动简介（200字以内）
- 引导用户提供：活动全称、具体参与方式、内容流程。
- 若为劳育，自动追加“单人服务时长X小时”。
- 若为线上活动，可提示附上活动群号。
- 自动检查是否出现完整活动名称，是否超过200字。

#### Step 7：生成申请表（所有字段填充）
- 自动填充第1~24项，输出完整申请表文本。
- 同时生成认定表的基础内容（活动分类、名称、学时、积分、地点、开始/结束时间、认定人数（同招募人数））。

#### Step 8：补充认定表特有字段（须用户提供）
- 提问：活动期间拍摄的照片（要求5M以内，可后期上传，此处先占位）
- 提问：活动总结（需写清楚何时何地做了何事，200~300字，引导用户按模板撰写）
- 自动生成认定表完整文档。

#### Step 9：输出校验报告
- 检查名称长度、时间顺序、学积分是否与分类匹配、简介字数等。

---

### 模式二：解析模式（上传策划书）

#### Step 1：上传策划书
- 用户提供策划书文件（.docx 或 .pdf）。
- Skill 自动读取并提取关键章节（活动背景、目的、时间、地点、对象、内容、流程等）。

#### Step 2：字段自动映射（依据策划书内容）
| 申请表字段        | 策划书中常见来源                                             |
| ----------------- | ------------------------------------------------------------ |
| 活动名称          | 策划书标题或“活动主题”                                       |
| 活动分类          | 根据内容推测（如涉及文化欣赏→美育；志愿服务→劳育等），并向用户确认 |
| 活动地点          | “活动地点”章节                                               |
| 活动开始/结束时间 | “活动时间”章节                                               |
| 招募人数          | “活动对象”或“参与人数”估算                                   |
| 活动级别          | 通常为“院级”（除非特别说明）                                 |
| 参与方式          | 根据活动内容判断（如征集比赛→观众/选手；讲座→观众）          |
| 活动简介          | 抽取“活动内容”+“活动流程”概括，自动精简至200字内             |
| 活动形式          | 根据内容归类（线上征集→其他，并说明“线上征集展示”）          |
| 联系人            | 若策划书有注明，则提取；否则留空并提示用户补充               |

#### Step 3：人工确认与修正
- 对自动提取的内容生成预览，列出每个字段的取值及来源。
- 提示需人工核对的敏感项：学时数量、积分数量、联系人信息、活动名称是否合规（可能超16字）。
- 允许用户修改任何字段。

#### Step 4：生成申请表与认定表
- 同模式一的 Step 7~Step 8，但部分字段已预填，用户只需确认或微调。

#### Step 5：生成认定表照片占位与总结草稿
- 照片：提示用户活动后补充拍摄证明。
- 活动总结：根据策划书流程自动撰写草稿（时间、地点、事件），字数控制在250字左右，用户可修改。

## 6. 校验规则（自动执行）

| 校验项       | 规则                                                         |

## 8. 注意事项（使用提醒）

- **所有活动不允许补发学时**，申请名额即最终名额，不可超发。
- 申请前务必与辅导员（宋婷老师）沟通学分数和积分。
- 认定表必须附带活动照片（截图或现场照）作为证明，否则无法认定。
- 上传系统时，活动名称以第二课堂发布的名称为准（若系统修改，认定表需同步）。
- 本 Skill 不替代人工审核，最终责任由活动负责人承担。
