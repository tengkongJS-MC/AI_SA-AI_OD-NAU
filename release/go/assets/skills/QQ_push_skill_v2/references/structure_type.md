# 推送文章结构模板

以下为校园推送的通用骨架，按"预告类 / 回顾类 / 科普类 / 栏目类 / 通知类"分型。所有推送都围绕：**吸睛开篇 → 主体介绍 → 安排/报名 → 激励结尾**。

## 通用要素清单（任何推送都应含）
- 一句话主题（常为"对仗式"四字/八字主题，如"以辩会友，以论启思"）
- 面向对象（"智慧农业学院（人工智能学院）全体同学"）
- 时间/地点/对象三要素（活动类必写）
- 激励点（学时 / 奖品 / 名额有限 / 先到先得）
- 行动号召（"快来参加""不见不散"）

---

## 一、活动预告类（活动报名 / 即将开始）
```
1. 吸睛标题： 主题金句｜"活动全名"
   例：淬言成锋，辩以砺才｜南京农业大学智慧农业学院（人工智能学院）2025级新生辩论赛火热来袭
2. 开篇引入： 问候 + 语气词 + 引出活动
   （"叮咚～""大家快来看""注意啦""来啦"）
3. 抛出共鸣/悬念： 提问或痛点（"你是否还在为…感到迷茫？"）
4. 活动意义/亮点： 2-4 句话介绍活动价值
5. 活动内容/形式： 分点或段落详述（报名/参赛/活动流程）
6. 活动安排：
   【活动时间】…
   【活动地点】…
   【面向对象】…
7. 报名方式： 扫码 / 加群 / 填写报名表 / 转发集赞
8. 结尾激励： 学时 + 奖品 + 名额有限 / 先到先得 + "心动不如行动，不见不散"
```

## 二、活动回顾类（圆满落幕 / 成果展示）
```
1. 标题： 活动全名 + "圆满落幕 / 完美收官 / 落下帷幕"
   例：AI赋能，跑耀冬日 | "AI 赋能 跑耀冬日"活动精彩收官
2. 抒情开场： 季节/氛围渲染（"金秋送爽，丹桂飘香…"）
3. 过程回顾： 描述现场氛围、精彩瞬间、选手表现
4. 成果/荣誉： 获奖名单、数据、意义
5. 感谢与展望： 致谢参与者/工作人员，期待下次再见
```

## 三、节日/节气科普类（全媒体）
```
1. 标题：【节日/节气名】
   例：【清明】【母亲节】【建军节】【立秋】
2. 起源由来： "…起于/源于/成立于…年，由…发起"
3. 历史/习俗/寓意： 介绍传统、风俗、象征意义
4. 人文内涵： 升华情感（团圆、思念、铭记、感恩）
5. 结尾祝福/共勉： "愿…""勿忘历史""共勉"
```

## 四、日常栏目类（全媒体）
```
1. 标题： 栏目名（【一期一会】【倾听你的声音】等）+ 本期主题
2. 温情开篇： 话题引入、引发共鸣
3. 主体内容： 分享/互动/征集主题
4. 结尾： 引导参与互动，期待投稿/留言
```

## 五、通知公告类（学院综合 / 组织部 / 宣传部）
```
1. 标题：【更名通知】/【活动速递】/【廉洁教育系列活动——XXX】
2. 正式开场："各位同学大家好！"
3. 事项说明： 清晰、分条陈述
4. 要求/时间节点： 明确到具体日期
5. 结尾： 敬请知悉 / 望相互转告 / 联系方式
```

---

## 部门结构偏好速查
- **学习部（讲座/宣讲）**：开篇抛问 → 主讲内容 → 讲座安排 → 收获点 → 报名
- **体育部（赛事）**：热血开篇 → 赛事介绍 → 时间地点 → 招募观众/志愿者 → 燃起来
- **文艺部（晚会/比赛）**：星光氛围 → 节目/赛制 → 报名 → "等你来战/C位"
- **生活部（宿舍主题）**：诗意季节开篇 → 活动内容 → 安排 → 温馨号召
- **组织部/分党校（思想类）**：庄重主题句 → 意义 → 内容 → 安排 → 青年担当号召
- **青协红会（志愿）**：温暖开篇 → 志愿服务内容 → 招募 → 报名 → 志愿学时/奉献号召
- **AI工坊（技术）**：活力开篇 → 技术内容 → 报名 → 成长/竞赛号召
