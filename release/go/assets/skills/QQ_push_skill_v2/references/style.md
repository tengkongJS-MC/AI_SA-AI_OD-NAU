# 语言风格指南

源自对该学院 776 条历史推送的语言统计提炼。写推送时遵循这些风格特征，才能"像"这个组织的文案。

## 一、整体语气：亲切活泼 + 年轻化
- 用亲昵称呼直接对话读者：**大家、同学们、小伙伴们、小可爱们、各位**
- 语气口语、亲切、有温度，像"学长学姐在群里招呼"而不是官方公告（除正式通知外）
- 多用感叹号「！」与波浪号「～」营造热情氛围
- 适当使用 emoji / QQ 表情（如 😄✨🎉📸🔴 或 [em] 标签）点缀
- 标题处固定采用（如 😄✨🎉📸🔴）相关emoji进行点缀
- ⚠️ **语气词要"少而自然"**：可少量出现"～""!"等点缀，但**不要**把"叮咚～""看过来""来啦"当万能模板反复堆叠——每个开篇都应结合活动内容原创，避免生硬、同质化。

## 二、标题：对仗主题 + 竖线副题
- 这里首先检查有没有从用户输入处获取到对仗的标题内容，如果有就直接使用这个主题标题，不需要自己进行生成和修改。
- 常使用**对仗式四字/八字主题**作为标题或副题，增强文采与记忆点：
  - 例：「淬言成锋，辩以砺才」「智汇青春力量，榜样筑梦同行」「以辩会友，以论启思」「映青春芳华，展寝室风采」「红韵党史砺初心，飞花传令记韶华」
- 结构常用：**主题金句｜活动全名**（竖线分隔）
  - 例：「AI 赋能，跑耀冬日 | 第三届"安踏杯"」「寻访家乡烟火，赓续本土文脉✨」
- 正式文体（通知/党建）标题带【】，如【活动速递】【廉洁教育系列活动——XXX】【清明】

## 三、开篇：由 AI 结合活动内容原创，杜绝模板腔
**核心原则**：开篇词要**结合本次活动内容原创**，先想"这个活动最打动人的点是什么"，再用它开场。禁止机械照搬"叮咚～""看过来""来啦"这类万能开头（生硬、且会让所有推送千篇一律）。

按所选结构（见 `structure.md` 8 种结构）选用对应开篇手法，开篇句要具体、贴合活动意象：
1. **主题引言式**：一句贴合活动的金句/对仗句开场（例：写演讲赛 → "言辞为剑，思想为锋…"）
2. **场景沉浸式**：一段季节/氛围白描制造画面（例：写秋日长跑 → "当银杏铺满校道，风里开始有了凉意…"）
3. **抛问共鸣式**：连抛贴近读者的提问（例：写四六级 → "听力靠蒙？阅读靠猜？这份焦虑你懂吗？"）
4. **直截了当式**：一句话直给核心信息，不绕弯（例：写球赛 → "本周六晚，院内杯决赛在篮球场开打。"）
5. **故事画面式**：一个小故事/人物细节切入（例：写志愿 → "上周的校园里，一个孩子踮起脚尖，把一朵野花递给了志愿者…"）
6. **成果荣誉式**：数据/成果先行（例：写回顾 → "历时两周，232 名选手、48 场对决…"）
7. **亮点爆点式**：先把嘉宾/奖品/福利抛出来（例：写讲座 → "这次，我们请到了 AI 领域的顶级大牛…"）
8. **正式公告式**："各位同学大家好"+目的（仅用于通知/党建/廉洁）

> **自查**：如果开篇句去掉活动名后可以套到任何一篇上，就说明写得太模板了，重写。

## 四、主体：活动价值 + 内容分述
- 用 2-4 句讲清活动"是什么、为什么值得参加"
- 突出收获点：**提升能力、结识朋友、收获学时、锻炼自我、助力升学/就业/竞赛**
- 活动内容可用分点、加粗小标题、emoji 列举

## 五、活动安排：固定三段式
```
【活动时间】具体到 日期+时段（例：11月1日晚18:30-20:00）
【活动地点】具体场所（润泽园广场 / 汇贤楼A104 / 操场）
【面向对象】南京农业大学智慧农业学院（人工智能学院）全体学生
```

## 六、报名/行动号召
- 高频词：**扫码、加群、填写报名表、报名方式、名额有限、先到先得、转发**
- 号召句：**心动不如行动、快来参加、不见不散、期待你的到来、等你来、欢迎大家踊跃报名**

## 七、结尾：激励 + 暖场
- 必带激励点：**第二课堂学时 / 精美奖品 / 证书**
- 常见收尾组合：「活动申请第二学时，创建QQ活动群，报名参加的同学进群…」「学时+奖品，名额有限先到先得」「心动不如行动，我们不见不散！」
- 科普/节日类以祝福或情感升华收尾

## 八、标点与排版习惯
- 感叹号、波浪号密集；短句为主，段落短小（适合手机阅读）
- 用【】标注"活动时间/地点/对象/活动形式"等字段
- 用「」或" "标注活动名、主题名
- 关键信息可加粗、换行突出

## 九、避免的腔调
- 不要写成冰冷官方公告（除非明确是通知/党建/廉洁类）
- **不要机械套用"叮咚～""看过来""来啦"等模板开篇**——每篇开篇都要原创、贴合活动
- **不要每篇都用同一套结构**——从 `structure.md` 的 8 种结构中随机换着用，避免同质化
- 不要过度堆砌华丽辞藻脱离活动实质
- 不要遗漏时间、地点、对象、报名方式等关键信息

## 十、各部门语气微调
- 学习部：务实上进，多"成长、提升、助力"
- 体育部：热血燃动，多"对决、挥洒、风采"
- 文艺部：星光艺术，多"舞台、热爱、C位"
- 生活部：温馨治愈，多"归属、第二个家"
- 组织部/分党校：庄重引领，多"青春担当、初心使命、红色基因"
- 青协红会：温暖奉献，多"爱心、微光、志愿"
- AI工坊：活力技术，多"动手、创新、工程师"
- 全媒体：文艺科普，多"来历、习俗、人文内涵"
