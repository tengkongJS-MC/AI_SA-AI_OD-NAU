# 校园新媒体推送写作

本 skill 让你能写出与"南京农业大学智慧农业学院（人工智能学院）"各学生组织历史推送同风格、同口吻、同术语的校园推送文案。

## 何时使用
用户要求写校园推送、部门活动文案、通知，或给出活动要素让你"像这个组织那样写"时触发。**不要**在用户要普通文章、报告、营销稿时使用。

## 工作流

### 第 1 步：收集与补全活动信息（主动引导）
动笔前先判断手上已有多少活动信息。若用户只给了一个宽泛需求（如"写一篇推送"）或信息零散，**主动向用户引导追问**，把关键细节补齐，避免凭空编造或遗漏。

**活动信息清单（引导用户逐项提供）**：

| 类别      | 需确认的细节                                             | 优先级    |
| ------- | -------------------------------------------------- | ------ |
| 部门      | 学习部/体育部/文艺部/生活部/组织部/分党校/青协红会/AI工坊/全媒体/宣传部/外联部/学院综合 | 核心     |
| 推送类型    | 活动预告 / 活动回顾 / 节日科普 / 日常栏目 / 通知公告                   | 核心     |
| 活动名称    | 活动全名（可帮起对仗式主题句）                                    | 核心     |
| 活动时间    | 具体日期 + 时段（如"11月1日晚18:30-20:00"）                    | 核心     |
| 活动地点    | 具体场所（润泽园/汇贤楼/博远楼/操场/大学生活动中心…）                      | 核心     |
| 面向对象    | 全体学生 / 某年级 / 新生 / 参赛者                              | 核心     |
| 奖励激励    | 学时 / 奖品 / 证书 / 加分（决定结尾话术）                          | 核心     |
| 报名方式    | 扫码 / 加群 / 填表 / 转发（活动类必带）                           | 核心<br> |
| 活动内容/环节 | 活动流程、比赛赛制、节目单、互动环节                                 | 建议     |
| 主办/协办方  | 主办部门、特邀嘉宾/评委、合作品牌                                  | 建议     |
| 特色亮点    | 活动区别于以往/竞品的卖点，用于"亮点抢先看"                            | 建议     |
| 语气侧重点   | 活泼/热血/庄重/温馨/正式                                     | 可选     |
| 篇幅与配图   | 是否配图/海报、篇幅长短                                       | 可选     |
| 数据库参照   | 写作时是否需要参照messages.json数据库：是/否                      | 必选核心   |
**数据库参照工作流：**
如果用户选择”是“，则阅读`data/messages.json`中的内容作为写作参考。

**引导原则**：
- 一次最多追问 **3-5 个核心项**（部门、活动、时间、地点、奖励），不要机械抛出一整张清单让用户填。
- 按"缺什么问什么"精准提问；用户给的信息越少，越要主动引导。
- 若用户明确表示"你看着定/你帮我编"或反复强调尽快给稿，则用**合理默认值**补全空缺（如用学院通用地点、常规学时、通配时间），并在交付时**明确标注哪些是默认补充的**，方便用户替换。
- 非核心项（嘉宾、环节、语气）缺省时按部门风格自动补写，无需逐一追问。

### 第 2 步：判断推送类型（内容定位）
在这里可以阅读`references/structure_type.md`去了解到不同种类推送的所需结构。
先明确内容定位，决定重心：
- **活动预告**（即将开始/报名）→ 重心在价值+安排+报名
- **活动回顾**（圆满落幕/成果）→ 重心在过程+成果+感谢
- **节日/节气科普** → 重心在来历+习俗+内涵
- **日常栏目**（征集/互动）→ 重心在话题+引导互动
- **通知公告**（更名/党建/廉洁）→ 重心在事项+要求
> 注意：这只是"内容重心"，**文章结构不按类型定**——结构在第 4 步从 8 种中随机选。

### 第 3 步：判断所属部门
根据活动内容归属部门，采用该部门语气。先读 `references/departments.md` 确定部门与风格要点。
- 宿舍/查寝/安全 → 生活部；运动会/球赛 → 体育部；歌手/晚会/戏剧 → 文艺部；辩论/讲座/四六级/考研 → 学习部；团校/团史 → 团委组织部；党课/党史/红色 → 分党校；志愿/公益/献血 → 团委青协红会；编程/算法/ACM → AI工坊；节气/节日/栏目 → 全媒体中心；廉洁 → 团委宣传部；商业合作 → 团委外联部。
- 同一活动以主办方为准（如"团校培训"归组织部，无论专题内容）。
- 无法明确归属（心理活动、综合通知）标"学院综合"，语气中性温情。

### 第 4 步：随机选择一种文章结构（避免同质化）
从 `references/structure.md` 的 **8 种结构**（A 主题引言式 / B 场景沉浸式 / C 抛问共鸣式 / D 直截了当式 / E 故事画面式 / F 成果荣誉式 / G 亮点爆点式 / H 正式公告式）中，**随机选用一种**作为本篇骨架——不要每次都用同一种结构。

- **随机选取**（可轮换，避免连续多篇雷同），再根据内容微调；结构与部门不绑定死（同一部门可用不同结构）。
- 无论选哪种结构，正文都要涵盖关键要素：主题句、意义/亮点、【时间】【地点】【对象】、报名/参与方式、结尾激励。
- **开篇由 AI 结合活动内容原创**：按所选结构的"开篇思路"现写，禁止照搬"叮咚～""看过来"等模板句。

### 第 5 步：融入风格与专有名词
- 语言风格、**原创开篇**、标点习惯 → 见 `references/style.md`
- 学院称谓、地点、学时、称呼、品牌活动名、命名范式 → 见 `references/terms.md`
- 各部门真实完整样例 → 见 `references/examples.md`

### 第 6 步：写正文并校验
按该部门口吻写完整文案，然后自查：
- [ ] **是否随机选用了一种结构**（非每次都同一种），且开篇**结合活动内容原创**、无"叮咚/看过来"模板腔
- [ ] 是否含吸睛标题与对仗主题句
- [ ] 是否含活动意义/亮点
- [ ] 活动类是否含【时间】【地点】【对象】
- [ ] 是否含报名/参与方式
- [ ] 结尾是否有激励点与行动号召
- [ ] 语气是否贴合所属部门（活泼/热血/庄重/温暖）
- [ ] 是否自然融入"智慧农业学院（人工智能学院）""第二课堂学时"等专有名词
- [ ] 是否为短句、分段落、适合手机阅读
- [ ] 是否有用户未提供、由你默认补全的信息（交付时明确标注，方便替换）

## 关键记忆点（快速参考）
- 学院固定称谓：**南京农业大学智慧农业学院（人工智能学院）**
- 称呼：**大家/小伙伴们/小萌新**；激励：**第二课堂学时**
- 高频场地：**润泽园、汇贤楼、博远楼、操场、大学生活动中心**
- 高频收尾：**心动不如行动、快来参加、不见不散、学时+奖品、名额有限先到先得**
- 标题范式：**对仗主题句｜活动全名**；科普用**【节日/节气名】**
- **8 种结构随机换用**（A-H 见 structure.md）；**开篇由 AI 原创**，禁用"叮咚/看过来"模板腔

## 输出
直接输出完整推送文案（QQ 空间风格，常用 emoji/[em] 点缀），无需额外包装。若用户提供了图片/海报需求可一并说明。若本次有默认补全的信息，文末用一行列出，便于用户核对替换。
