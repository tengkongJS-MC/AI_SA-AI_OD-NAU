# 配图参数引导

动笔生成提示词前，**先向用户询问图片基本参数**（尤其比例），避免凭空设定。用户给出后据此生成。

## 参数清单（按优先级）

### 1. 图片比例（必问）
| 比例 | 适用场景 |
|---|---|
| 横版 16:9 | 公众号头图、横幅、电脑端封面 |
| 竖版 9:16 | QQ 空间、朋友圈、手机全屏、短视频封面 |
| 方形 1:1 | 头像、社媒方图、封面卡片 |
| 3:4 / 4:5 | 小红书、竖版封面、种草图 |
| 1.91:1 | 公众号题图、横版主视觉 |

> 若用户未指定，按用途推断：QQ 空间/朋友圈默认 **9:16 竖版**，公众号默认 **1.91:1 或 16:9**。

### 2. 图片数量
- **主图（固定配图）**：必配 1 张，承载活动主题，作为封面/头图。
- **辅助配图（反映活动情况）**：建议 2-4 张，可描述活动场景、元素、氛围、人物等。
- 询问用户需要几张配图；不指定则默认"主图 1 张 + 3 张辅助配图"。

### 3. 图片风格
询问用户偏好，常见选项：
- 写实摄影 / 扁平插画 / 国潮 / 科技赛博 / 水彩 / 3D 卡通 / 手绘粉笔 / 剪影极简
- 不指定时，按 `style-guide.md` 中部门对应风格自动推荐。

### 4. 是否要文字（重要）
- **主图**通常需要**活动主题大字**（作为封面标题），需确认主题文字内容。
- 辅助配图一般不需要文字（或仅少量点缀）。
- 提示词中用中文引号「"文字"」明确标注需生成的文字。

### 5. 色彩倾向
- 询问主色调 / 冷暖；不指定时按部门风格配色。

### 6. 用途
- QQ 空间 / 公众号 / 海报 / 短视频封面——影响比例与文字排版方式。

## 引导原则
- 一次最多问 **3-4 个核心项**（比例、数量、风格、要不要文字），不要一次抛全部参数。
- 用户信息不足时，用合理默认值补全（默认 9:16、主图+3 配图、按部门风格），并在交付时标注默认值。
