# 推送配图提示词生成

本 skill 让推送不仅有文案，还有配套的图片：为每一份推送生成 1 张**带活动主题的固定主图**（封面/头图），以及若干**反映活动情况的辅助配图**的**图片生成提示词**（供后续文生图使用）。

## 何时使用
用户已完成（或正在写）校园推送，需要配套配图、封面图、海报底图、头图，或要求"生成配图提示词"时触发。与 `campus-push-writer`（写文案）配合使用。

## 工作流

### 第 1 步：收集图片基本参数（主动询问）
先向用户询问基本参数，再生成提示词，避免凭空设定。详见 `references/parameters.md`。
- **必问核心项**（一次 3-4 个）：**图片比例**（9:16 / 16:9 / 1:1 / 3:4…）、**图片数量**（主图+几张配图）、**风格**（写实/插画/国潮/科技…）、**是否要主题文字**。
- 建议确认：色彩倾向、是否融入院徽/吉祥物"小AI"、用途（QQ空间/公众号/海报）。
- 用户信息不足时用合理默认（默认 9:16 竖版、主图 1 张+3 张配图、按部门风格），并在交付时标注默认值。

### 第 2 步：解析推送与活动，确定图片风格
- 通读推送文案与活动内容，提取：**部门、活动主题、推送类型（预告/回顾/科普/栏目/通知）、核心元素、情绪基调**。
- 从 `references/style-guide.md` 匹配**部门主视觉**（配色/元素/氛围），叠加**推送类型**的情绪倾向（预告=期待、回顾=荣耀、科普=清雅…）。
- 确定**主图**与**辅助配图**各自的画面侧重。

### 第 3 步：生成提示词
按 `references/prompt-structure.md` 的模板生成：
- **主图（固定配图，必配 1 张）**：承载活动主题，含大标题文字、封面级辨识度、与部门风格一致。画面中需生成的主题文字用中文引号标注（如"迎新杯篮球赛"）。
- **辅助配图（反映活动情况，若干张）**：以活动场景、元素、人物、氛围为主，与主图同一风格体系，可不含文字。
- 每条提示词写清：主体、活动元素、风格、配色、构图、氛围、画面文字、比例。

### 第 4 步：校验并输出
自查：
- [ ] 是否已确认图片比例（或已标注默认）
- [ ] 主图是否**承载活动主题文字**，且与部门风格匹配
- [ ] 辅助配图是否**反映活动实际情况**、与主图成套
- [ ] 提示词是否具体可生成（主体/风格/配色/构图/氛围/比例齐全）
- [ ] 是否有用户未提供、由默认补全的参数（标注出来）

## 关键记忆点
- 每份推送**必有 1 张固定主图**（含活动主题）+ 若干辅助配图。
- 图片风格 = **部门主视觉**（style-guide.md）+ **推送类型情绪**。
- 主图要"封面级"：预留标题区、有辨识度；辅助配图强调"反映活动情况"。
- 需生成的文字用中文引号标注，如"活动主题"。

## 输出
分组输出提示词（主图 / 配图1 / 配图2…），每条注明画面描述与比例。若与 `campus-push-writer` 联用，优先沿用该推送的部门与主题。
