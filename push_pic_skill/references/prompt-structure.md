# 图片提示词结构模板与示例

图片提示词要**具体、可生成**：说清主体、元素、风格、配色、构图、氛围、比例、文字。中英文均可，需生成文字时用中文引号标注。

## 一、主图（固定配图，含活动主题）提示词模板
```
[一张 部门 主题 的 风格 图片]
主体：[画面核心（什么场景/人物/物件）]
活动元素：[与活动直接相关的视觉元素，2-4 个]
风格：[插画/写实/国潮/科技… 从 style-guide 选]
配色：[主色系 + 点缀色]
构图：[构图方式 + 标题文字预留位]
氛围：[情绪，如期待/热血/温馨/庄重]
画面文字：需出现中文大字"[活动主题/对仗主题句]"
比例：[如 9:16 / 16:9 / 1:1]
```

## 二、辅助配图（反映活动情况）提示词模板
```
一张 [部门/活动名] 相关配图，[画面场景或人物]
[风格 + 配色 与主图保持一致]
[氛围 + 细节]
比例：[与主图一致]
```
辅助配图通常**不强制文字**，强调"反映活动实际情况"（现场、元素、人物互动、成果）。

## 三、示例

### 示例 1｜学生会学习部 · 期中考试（主图）
> 一张学生会学习部期中考试主题的扁平插画风封面图。主体为一张木色书桌，摊开的课本、翻开笔记、签字笔与手表；背景是明亮的大学图书馆书架；风格扁平清新、构图居中、留出顶部标题区；配色以清爽蓝青色为主、点缀暖黄；氛围理性向上、略带紧张感；画面需出现中文大字"以考促学，笃行致远"；比例 9:16 竖版。

### 示例 2｜学生会体育部 · 迎新杯篮球赛（主图）
> 一张体育部篮球赛主题的写实动感封面图。主体为一名大学生跃起投篮的剪影，篮球划过弧线，身后是燃烧火焰般的橙色赛场氛围；动态慢门虚化背景、高对比、热血冲击感；底部色块上放标题；配色橙红+深蓝；画面需出现中文大字"迎新杯篮球赛"；比例 16:9 横版。

### 示例 3｜学习部期中考试（辅助配图 · 反映活动情况）
> 一张与主图同风格的插画配图：傍晚自习室里，几名大学生伏案答题、认真专注的侧面剪影，桌上摊着试卷与文具，窗外透进暖光；蓝青主色、暖黄点缀，氛围安静专注；比例 9:16。

### 示例 4｜分党校 · 党史红色活动（主图）
> 一张分党校红色主题的国潮风封面图。主体为迎风飘扬的红旗与巍峨长城剪影，上方是金色的五角星与光束，底部为青年群像侧影；中国红+鎏金配色、庄重大气；画面需出现中文大字"红色基因，薪火相传"；比例 1:1 方形。

## 四、输出格式
按"主图 + 辅助配图"分组输出提示词，每条注明：**图序（主图/配图1/配图2…）、画面描述、比例**。若某条参数由默认补全，单独标注。
