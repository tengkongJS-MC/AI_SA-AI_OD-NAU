# 图片风格库（按部门 / 推送类型）

确定图片风格时，优先匹配推送所属**部门**的视觉语言，再叠加**推送类型**的情绪倾向。以下配色、元素、氛围、风格关键词可直接用于提示词。

## 一、按部门（决定主视觉基调）

| 部门 | 主色 | 核心元素 | 氛围/风格关键词 |
|---|---|---|---|
| 学生会学习部 | 蓝 / 青 / 清新 | 书本、笔、笔记本、阶梯、灯塔、目标箭头 | 理性、清爽、上进；写实或扁平 |
| 学生会体育部 | 红 / 橙 / 明黄 | 球场、球、球鞋、奔跑身影、奖杯、汗水 | 热血、动感、活力；动态构图、高对比 |
| 学生会文艺部 | 紫 / 粉 / 星光金 | 舞台、聚光灯、麦克风、音符、星星、丝带 | 梦幻、浪漫、星光；霓虹、氛围光 |
| 学生会生活部 | 暖黄 / 绿 / 奶油 | 宿舍、绿植、暖灯、被子、咖啡、温馨日常 | 温馨、治愈、居家；暖光插画 |
| 团委组织部 | 红 / 金 / 深蓝 | 团旗、齿轮、五角星、青年剪影、书卷 | 庄重、青春、引领；正式、构图规整 |
| 分党校 | 中国红 / 金 / 米白 | 红旗、党徽意象、长城、山河、火炬 | 庄重、红色、伟岸；写实或国潮 |
| 团委青协红会 | 红 / 白 / 温暖橙 | 爱心、双手、志愿者马甲、微光、孩童 | 温暖、奉献、明亮；柔光、亲肤 |
| AI工坊 | 蓝紫 / 赛博青 | 电路、代码、机器人、芯片、智能农业、无人机 | 科技、未来、创新；赛博、玻璃拟态 |
| 全媒体中心 | 依节气/节日氛围 | 节气元素（叶、雪、花）、传统意象 | 文艺、空灵、摄影感 |
| 团委宣传部 | 青 / 白 / 竹青 | 莲花、竹、清泉、云 | 清雅、正直、廉洁；留白 |
| 团委外联部 | 时尚亮色 / 品牌色 | 城市、霓虹、礼品、现代建筑 | 潮流、商业、都市感 |
| 学院综合 | 学院主视觉（红蓝相间） | 校徽、教学楼、青春群像 | 中性、大气、统一 |

## 二、按推送类型（决定情绪与构图倾向）

| 类型 | 情绪 | 构图/画面倾向 |
|---|---|---|
| 活动预告 | 期待、邀约 | 开放式构图，留出标题区；"即将开启/等你来"感 |
| 活动回顾 | 荣耀、感动 | 成果感，可含奖杯、数据、合影、高光瞬间 |
| 节日/节气科普 | 清雅、静谧 | 元素化特写，节气/节日符号，图文留白 |
| 日常栏目 | 治愈、陪伴 | 稳定栏目视觉模板，温情小元素 |
| 通知公告 | 正式、简洁 | 规整居中，少装饰，信息优先 |

## 三、主图 vs 辅助配图
- **主图（固定配图）**：承载活动主题，画面需预留标题文字位，视觉有辨识度、可直接做封面。
- **辅助配图（反映活动情况）**：以活动场景、元素、人物、氛围为主，与主图同一风格体系，但可不含主题文字；可覆盖多个视角（活动概览、局部细节、人物互动、成果展示）。

## 四、通用加分项
- 统一风格体系：同批配图保持一致的配色、画风、光感，保证成套感。
- 主图可适度用"大主题字 + 底部色块/光晕"增强标题可读性。
- 吉祥物 **"小AI"** 可作固定 IP 点缀（技术/学院类）。
