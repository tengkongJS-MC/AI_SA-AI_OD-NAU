# 专有名词与信息库

写作时自然融入这些学院专属名词，可大幅提升"像本院推送"的真实感。

## 一、机构 / 组织
- 南京农业大学（**南农**）
- 智慧农业学院（**人工智能学院**）—— 正文常用"人工智能学院""智慧农业学院"
- 分党校（下设：分党校学习部、分党校宣传部、分党校实践部、分党校档案部）
- 团委（下设：团委组织部、团委宣传部、团委监察部、团委外联部、团委青协红会）
- 学生会（下设：学生会学习部、学生会体育部、学生会文艺部、学生会生活部、学生会秘书处）
- **AI工坊**（下设：研发处、秘书处、赛事部、创新创业部、培训部、宣传交流部）
- 全媒体中心、主席团

## 二、地点
- **润泽园**（广场，校园活动高频场地）
- **汇贤楼**（教学楼，A104/D101/D301 等教室常办讲座/比赛）
- **博远楼**（教学楼）
- **操场 / 田径场 / 篮球场 / 羽毛球场**
- **大学生活动中心**、图书馆、体育馆、食堂、宿舍
- 浦口校区（校本部为卫岗校区）

## 三、激励与学分
- **第二课堂学时**（简称"学时"，活动参与激励，出现频率最高）
- **PU 学时**、学分、奖品、证书
- 常写"活动申请第二学时""丰厚学时等你来拿"

## 四、称呼昵称
- **小AI**（学院/AI工坊拟人化自称，技术类推送常用"小AI陪你…"）
- **团团**（团组织昵称）
- **萌新 / 小萌新**（新生）、**学长学姐**
- 面向对象固定写法：**南京农业大学智慧农业学院（人工智能学院）全体学生/全体同学**

## 五、常用主题词（按部门）
- **学习部**：学风、考研、保研、四六级、分流、讲座、宣讲、学霸、笔记、SRT、职业规划、名企
- **体育部**：迎新杯、院内杯、校运会、四项、对决、热血、挥洒汗水
- **文艺部**：歌手大赛、晚会、舞台、星光、艺术团、礼仪队、IP形象
- **生活部**：宿舍文化节、查寝、舍徽、装扮、安全、春日、寓见美好
- **组织部**：团校、青马工程、团史、团支部、入团、青年大学习、两会、二十大精神
- **分党校**：党课、入党、党史、红色基因、初心使命、革命精神、遵义、井冈山、长征、两弹一星
- **青协红会**：志愿、公益、献血、支教、敬老、环保、三下乡、返家乡、实践团、义务讲解
- **AI工坊**：ACM、程序设计、算法、机器人、软件、H5、网络安全、创新创业、挑战杯

## 六、品牌化活动名（高频出现，可复用命名范式）
- 新生辩论赛（"淬言成锋，辩以砺才""涌动青春思辨，论道谁与争锋"）
- 宿舍文化节（"'宿'说青春，'寓'见美好""与你相'寓'"）
- 心理月/心理周（"与心相约，与AI同行""心语心愿，情暖意舒"）
- AI 科研月（留学/考研保研/科研系列讲座）
- 迎新杯 / 院内杯 篮球赛
- 春季/冬季四项运动会
- 歌手大赛、英语配音大赛、校园主持人大赛
- 毕业季、军训季、迎新季专题
- 百廿校庆（120 周年）系列
- 节日节气栏目（【清明】【冬至】【国庆】等）
- 栏目：【一期一会】【倾听你的声音】【AI青春正当时】

## 七、命名范式（重要！写新活动时套用）
- **对仗式主题**：四字+四字或二字+二字成对，如"淬言成锋，辩以砺才""红韵党史砺初心，飞花传令记韶华"
- **谐音玩梗**：宿舍类常用"寓"谐音（"寓见美好""与你相'寓'"）
- **英文缩写+中文**：AI+主题（"AI赋能，跑耀冬日""AI 绘志愿，'智'造新形象"）
- **主题｜活动全名** 的标题格式

## 八、时间表达
- 高频用"每年公历…""每年X月第X个星期X"讲节日/节气（科普类）
- 活动时间写具体到时段（"本周五晚19:00-20:30"）
- 节日常用"一年一度的…来啦"
