# 推送文章结构库（8 种结构，写作时随机选用）

以下是从历史推送中提炼的 **8 种结构骨架**。每次写作时**随机/按内容选择一种**作为整体骨架，避免所有推送千篇一律。核心不变：**独特开篇 → 主体 → 安排/报名 → 激励结尾**。

> **开篇铁律**：开篇词必须**结合本次活动内容原创**，禁止机械套用"叮咚～""看过来""来啦"等模板腔。下面每种结构的"开篇手法"给出的是思路，不是可直接照抄的句子——由你据活动现写。

---

## 结构 A｜主题引言式（诗意带入）
**开篇手法**：用一句对仗主题句或诗化金句先声夺人，营造文采与仪式感，再自然点出活动。
```
1. 标题： 对仗主题句｜"活动全名"
2. 开篇： 一句凝练金句/主题句（不是"叮咚"，而是贴合活动意象的句子）
3. 引子： 由这句金句过渡到活动本身
4. 意义/亮点
5. 内容/形式
6. 【时间】【地点】【对象】
7. 报名方式
8. 激励结尾
```
**适用**：文艺、全媒体、生活部等有氛围感的活动。

## 结构 B｜场景沉浸式（氛围渲染）
**开篇手法**：用一段季节/时间/空间的白描制造画面感（如"当夏日的风掠过林梢""夜色渐浓，台灯亮起"），把读者带入情境，再带出活动。
```
1. 标题： 活动名/主题
2. 开篇： 一段场景白描，营造氛围（画面、感官、情绪）
3. 转折： "就在此时/趁此…"，把场景与活动衔接
4. 活动介绍
5. 【时间】【地点】【对象】
6. 参与方式 / 报名
7. 激励结尾
```
**适用**：文艺、季节类、生活类、回顾类。

## 结构 C｜抛问共鸣式（提问引导）
**开篇手法**：连抛 2-3 个贴近读者处境的提问，触发共鸣与代入感，再引出解决之道（活动）。
```
1. 标题： 对仗主题句｜"活动全名"
2. 开篇： 连续提问（2-3 个，围绕读者的痛点/好奇/期待）
3. 转折： "别担心/其实/机会来了" → 引出活动
4. 活动价值（回应前文问题）
5. 内容/形式
6. 【时间】【地点】【对象】
7. 报名方式
8. 激励结尾
```
**适用**：学习部、讲座、考研/四六级、求职等"解决困惑"型活动。

## 结构 D｜直截了当式（开门见山）
**开篇手法**：第一句话直接亮出活动名 + 最核心信息（时间/地点/对象），干净利落，不绕弯。
```
1. 标题： 活动全名（可直接带时间地点）
2. 开篇： 一句话直给核心（"XX活动将于X月X日X时在X地举行，面向…"）
3. 补充： 活动内容、赛制、流程
4. 【时间】【地点】【对象】
5. 参与方式 / 注意事项
6. 激励/号召结尾（简短）
```
**适用**：体育赛事、考试通知、干货型、紧急信息。

## 结构 E｜故事画面式（叙事切入）
**开篇手法**：用一个小故事、一个具体人物动作或细节画面切入（"校道上，一个背着球包的身影匆匆而过…"），以叙事勾住读者，再揭示主题。
```
1. 标题： 主题｜活动全名
2. 开篇： 一个小故事/人物/细节画面（具体、可感）
3. 点题： 由故事引出活动
4. 活动介绍
5. 【时间】【地点】【对象】
6. 报名/参与
7. 激励结尾（呼应开篇故事）
```
**适用**：志愿、温情、回顾、人物类活动。

## 结构 F｜成果荣誉式（数据先行）
**开篇手法**：先用成果、数据、奖项、规模"砸"开场（"本届大赛吸引200余名选手参赛，历时一个月…"），先立威再展开。
```
1. 标题： 活动全名 + "圆满落幕/战报"
2. 开篇： 数据/成果/荣誉先行（参赛规模、获奖、反响）
3. 过程回顾： 亮点、精彩瞬间、选手表现
4. 荣誉/名单
5. 感谢与展望
6. 激励结尾（祝福/期许）
```
**适用**：活动回顾、赛事战报、总结表彰。

## 结构 G｜亮点爆点式（价值开场）
**开篇手法**：先把最吸引人的"爆点"抛出来——重磅嘉宾、丰厚奖品、稀有名额、新颖形式，第一时间抓住眼球。
```
1. 标题： 活动全名（可加"重磅/震撼来袭"）
2. 开篇： 抛出爆点（嘉宾/奖品/福利/名额/亮点）
3. 展开： 活动全貌、内容、赛制
4. 【时间】【地点】【对象】
5. 报名方式
6. 激励结尾（呼应爆点）
```
**适用**：大赛、明星嘉宾、福利型、商业合作活动。

## 结构 H｜正式公告式（官方开场）
**开篇手法**："各位同学大家好" + 一句目的说明（"为深入学习贯彻…""为进一步规范…"），正式、条理清晰。
```
1. 标题：【通知/活动速递/廉洁教育系列活动——XXX】
2. 开篇： "各位同学大家好！" + 目的/背景（正式）
3. 事项说明： 分条、清晰陈述
4. 时间节点 / 要求
5. 结尾： 敬请知悉 / 望相互转告 / 联系方式
```
**适用**：通知公告、党建、廉洁、纪律、正式文件。

---

## 如何选择与组合
- **每次写作前先随机选一种结构**（或用骰子式随机），避免连续多篇都用同一结构。
- 结构可**微调组合**：如"场景沉浸式开篇 + 数据成果式结尾"，但骨架整体取一种为主。
- 结构与部门不绑定死：同一部门的不同推送可用不同结构（如学习部可用 C 提问式，也可用 D 直给式）。
- 开篇手法务必**结合活动内容原创**，同一种结构在不同活动下写出不同开篇。
