常见问题

Windows 提示「已保护你的电脑」怎么办？

程序未做代码签名。点提示里的「更多信息」→「仍要运行」即可；也可先核对页面上的 SHA256 与官方 Release 一致。

需要先安装什么运行环境？

不需要。exe 已内置全部依赖，只需系统自带 WebView2 运行时（Windows 10/11 一般已预装）。

API Key 从哪来？会不会被上传？

用智谱开放平台或 DeepSeek 开放平台的 Key，在应用右上角「⚙ 模型设置」里填写。Key 仅保存在本机配置文件中，请求由你的电脑直连模型服务。

为什么导出的 Word 是公文格式？

按学院公文规范排版：A4、正文仿宋四号、首行缩进 2 字符、固定行距，一级标题黑体、二级楷体、三级仿宋；策划案自动套封面并分页，经费预算导出为真实表格。

可以换配色吗？

可以。应用内置经典红、浅蓝、浅绿、浅黄与深色五套主题——界面预览标题栏那五个小圆点就是它们，点一下整页都会跟着换。

Skill 包是什么？不装程序也能用吗？

Skill 包是策划案、QQ 推送、微信推送、配图提示词、学时表单五个技能的规则与参考文档，纯 Markdown 文本，共 66 KB。解压后把某个 skill 文件夹里的 SKILL.md 连同同目录的 references/ 一起拖进 AI 聊天框，再说一句你的需求，它就会照着这套规则写；包内 README.md 有完整教程与示例话术，不想用桌面程序也能直接使用。
