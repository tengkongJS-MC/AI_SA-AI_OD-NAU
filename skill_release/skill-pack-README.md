# 智农 · AI 组织部 写作技能包 · v1.2

面向南京农业大学智慧农业学院（人工智能学院）团委组织部的**写作提示词技能包**。

解压后，把里面的 Markdown 文件丢给任意大模型（DeepSeek / 豆包 / Kimi / 通义 / ChatGPT / Claude…），
它就能按学院的固定模板、公文话术和新媒体系列风格帮你写材料——**不需要安装任何软件**。

---

## 一、包里有什么

| 目录 | 用途 | 入口文件 | 建议一起带上 |
|---|---|---|---|
| `plan_skill/` | 活动策划案（固定模板 → 待确认清单 → 定稿） | `SKILL.md` | `references/knowledge-base.md` |
| `QQ_push_skill_v2/` | QQ 空间推送（按部门 / 推送类型） | `SKILL.md` | `references/` 下全部 6 个 md |
| `wechat_push_skill/` | 微信公众号推送（官方号调性） | `SKILL.md` | —（单文件） |
| `push_pic_skill/` | 配图图片提示词（主图 + 辅助配图） | `SKILL.md` | `references/` 下全部 3 个 md |
| `time_skill/` | 第二课堂学时申请 / 认定表 | `time.md` | —（单文件） |

> ⚠️ **重点**：这些技能内部有「引用关系」——`SKILL.md` 里会点名 `references/` 里的词库
> （部门话术、范文、风格库、评分口径等）。只丢 `SKILL.md` 也能用，但**带上 `references/` 效果明显更好**，
> 所以推荐**整个文件夹一起拖**。

## 二、最快用法：拖进 AI 聊天框（30 秒上手）

1. 把本压缩包**解压**到任意位置（桌面即可）。
2. 打开一个支持上传 / 拖拽文件的 AI 对话（DeepSeek、豆包、Kimi、通义、ChatGPT、Claude 都行）。
3. 把某个技能文件夹里的**全部 `.md` 文件**（或直接拖整个文件夹）**拖进聊天框**。
4. 在输入框补一句"你要写什么"，回车发送即可。

### 示例 · QQ 空间推送
> 〔拖入 `QQ_push_skill_v2/` 里的全部 md〕
>
> 帮我写一条 QQ 空间推送：文艺部「春日序曲」摄影展，3 月 10 日全天，线上征集作品，
> 奖励美育学时 + 奖品，报名方式扫码进群。用活动预告的风格，短句分段。

### 示例 · 策划案
> 〔拖入 `plan_skill/SKILL.md` 与 `plan_skill/references/knowledge-base.md`〕
>
> 按这个技能写一份「迎新杯篮球赛」策划案：院级，10 月 15 日下午，浦口校区操场，
> 24、25 级各团支部，预计 120 人，经费按知识库常见科目拟列。

### 示例 · 学时申请
> 〔拖入 `time_skill/time.md`〕
>
> 按这个技能生成学时申请表：美育实践，活动名称「智农院春日摄影展观众」，
> 报名 2026-03-01 08:00 起，活动 2026-03-10 08:00—12:00，线上，预计 100 人，
> 参与方式观众，申请 2 学时、1 积分。

### 示例 · 配图提示词
> 〔拖入 `push_pic_skill/` 里的全部 md〕
>
> 给下面这篇推送生成配图提示词：9:16 竖版，主图带主题大字「春日序曲」，
> 风格扁平插画，暖色调，主图 1 张 + 辅助配图 3 张。〔然后粘贴你的推送文案〕

### 示例 · 微信推送
> 〔拖入 `wechat_push_skill/SKILL.md`〕
>
> 写一篇活动总结推文：我院春日摄影展圆满落幕，收到作品 120 余件，面向在校生，
> 目的是记录过程。要标题、正文与页脚信息栏。

## 三、如果对话框只能贴文本（不能上传文件）

用记事本 / VS Code 打开 `SKILL.md`（有 `references/` 的一并打开）→ **全选复制** →
粘贴到对话的**最前面** → 再在下面写你的需求。
效果等同于"把技能当成开场白"，只是每次新开对话都要再贴一次。

## 四、更省事的做法：用桌面版

桌面版（`AIOD-Writer-Go-v1.2.exe`）**已把下面这 5 个技能全部内置**，
打开就是「填表 → ✦ 生成全文 → 选中改写 → 导出 Word」，不需要手动拖文件。

技能包更适合这些场景：
- 想在别的 AI（豆包 / Kimi / ChatGPT…）里直接用；
- 想自己改提示词（md 就是纯文本，改完保存再拖进去就是你的新版本）；
- 只想把某一个技能分享给同学。

## 五、常见问题

**Q：只拖 `SKILL.md` 行不行？**
行，但会缺 `references/` 里的词库（部门话术、范文、风格库、评分口径），产出会明显"不像"。

**Q：文件太大贴不进去？**
优先贴 `SKILL.md`；`references/` 里挑最相关的 1—2 个（例如写 QQ 推送时补 `style.md` + `examples.md`）。

**Q：模型回"请提供更多信息"怎么办？**
正常。技能里本来就写了"信息不足用占位符并用合理默认值补全，最后标注哪些是默认值"。
你也可以直接回它：**用合理默认值补全，并在末尾标注待确认项**。

**Q：会不会写错学分数、金额、教室号？**
技能里明确要求这类变动信息必须列入"待确认清单"，不得杜撰。
最终请以辅导员（学时/积分）与学院现行报销制度为准。

**Q：内容里还有真实人名吗？**
技能包内的功能型文件已对真实人名 / 学号做过占位处理，可放心分享。

**Q：能不能用于写作以外的用途？**
这些是**写作规范**（模板、话术、结构、禁忌），不是通用知识库，请按上面各技能的适用范围使用。
